# 자연어 통계 분석 실습지

- 함께 보기 = [강의 본문](lecture.md) · [실행 안내](../README.md#설치와-로컬-점검).
- 입력 위치 = `python handson.py` 실행 뒤 질문 입력란; API 없이 결과 확인은 `python examples/analyze_baseline.py`.
- 답변 기록 = 요청한 기준·사용 도구·실제 숫자·수정할 해석 구분.

## 실습 1 · 질문 전에 데이터 읽기

```text
먼저 데이터의 행 수·열 수·자료형·결측 수를 확인해줘.
Purchase와 User_ID가 모두 숫자라고 같은 방식으로 분석해도 되는지 설명해줘.
```

- 대조 = 550,068행·12열; Purchase 결측 0개.
- 사람의 판단 = 식별자의 평균이 분석 질문에 의미 있는지 구분.
- 주의 = 고객 고유값 수 5,891개는 별도 기준 계산에서 확인한 값; 현재 세 도구에 고유값 계산 기능은 없음.

## 실습 2 · 평균 하나로 충분한가

```text
Purchase의 유효 관측 수·평균·중앙값·최솟값·최댓값을 계산해줘.
계산 결과와, 추가 확인이 필요한 해석을 나눠 설명해줘.
```

- 대조 = 550,068개 / 평균 9,263.97 / 중앙값 8,047 / 범위 12–23,961.
- 사람의 판단 = 평균과 중앙값 중 질문에 맞는 요약값 선택, 분포를 추가 확인할 이유 기록.
- 미확인 = 통화·수집 기간·극단값의 발생 이유.

## 실습 3 · ‘많다’의 기준 바꾸기

```text
Age별 Purchase의 유효 건수·평균·중앙값·합계를 비교해줘.
건수가 가장 큰 집단과 평균이 가장 큰 집단을 각각 알려줘.
집단별 차이를 연령 때문에 생긴 차이라고 단정하지 마.
```

- 대조 = 건수 최대 `26-35` 219,587개; 평균 최대 `51-55` 9,534.81.
- 사람의 판단 = 구매 레코드가 많은 것과 고객 한 명이 많이 구매하는 것을 구분.
- 이어갈 질문 = 고유 고객별 집계와 상품 구성 차이를 비교하려면 어떤 도구가 더 필요한가?

## 실습 4 · 잘못된 해석 고치기

```text
“26–35세 고객은 219,587명이고, 51–55세는 소득이 높아 많이 산다”라는 문장을 검토해줘.
현재 계산으로 확인한 사실·근거 없는 해석을 구분하고 고친 문장을 제안해줘.
```

- 찾아낼 오류 = 레코드 수와 고객 수 혼동; 없는 소득 자료로 원인 설명.
- 사람의 수정 = 비교 단위·기준·숫자·한계를 포함한 결론 한 문장 작성.
- 기록 = 내가 고른 문장과 이유; AI가 검증하지 않은 내용은 미확인 유지.

## 실습 결과 기록

| 항목 | 내가 채울 내용 |
| --- | --- |
| 처음 질문 | 무엇을 알고 싶은가 |
| 분석 기준 | 대상·단위·집계 방식 |
| 계산 근거 | 사용 도구·확인한 숫자 |
| 수정한 문장 | AI 제안에서 바꾼 부분 |
| 남은 확인 | 자료 조건·추가 분석 |

- 완료 기준 = 세 계산을 원자료 기준 결과와 대조하고, 근거 없는 해석을 직접 수정.
- 자료 성격 = 새로 재구성한 실습; 고정된 답변 예시를 실시간 AI 응답으로 표기하지 않음.
